
# IYF Season 12 – Week 7 Project

## Project Overview
This project builds on my Week 5 JavaScript To-Do List and introduces modular JavaScript, localStorage, automated testing, and code quality tools.

## Features

### 1. To-Do List
- Add, edit, and delete tasks.
- Mark tasks as completed.
- Filter tasks by All, Active, and Completed.
- Clear completed tasks.
- Save tasks using localStorage.
- Retain tasks after refreshing the page.

### 2. Shopping Cart
- Display products with images and prices.
- Add products to the cart.
- Increase and decrease quantities.
- Remove individual products.
- Calculate cart totals and item counts.
- Save cart contents using localStorage.

### 3. Daily JavaScript Challenges
- FizzBuzz
- Reverse a String
- Find the Largest Number
- Remove Duplicates from an Array
- Palindrome Checker

## Technologies Used
- HTML5
- CSS3
- JavaScript ES Modules
- Node.js
- Vitest
- ESLint
- Prettier
- localStorage
- Git and GitHub

## Project Structure
- `js/` – To-Do application modules
- `tests/` – Automated tests
- `cart/` – Shopping cart project
- `daily-challenges/` – Five JavaScript exercises

## Installation and Setup

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Run tests:

   ```bash
   npm test
   ```

4. Run ESLint:

   ```bash
   npm run lint
   ```

5. Open `index.html` using VS Code Live Server.
